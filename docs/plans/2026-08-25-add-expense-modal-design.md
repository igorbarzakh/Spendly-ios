# Spendly Add Expense Modal Design

**Дата:** 2026-08-25
**Статус:** утверждено
**Цель:** добавить нативный модальный экран создания расхода в SwiftUI без выбора пространства

## 1. Паттерн показа

Экран открытия новой траты показывается как модальная `sheet` поверх вкладки расходов. Внутри sheet используется `NavigationStack`, чтобы получить системную верхнюю область, корректную работу `toolbar` и дальнейшую возможность открывать вложенные экраны выбора категории, даты или товарных позиций.

Экран не использует push-навигацию. Закрытие происходит только через верхние действия отмены и сохранения либо системный свайп sheet.

## 2. Верхняя панель

- Заголовок: `Новая трата`
- Слева: круглая кнопка `xmark` для отмены
- Справа: круглая кнопка `checkmark` для сохранения

Правая кнопка остается серой и неактивной, пока не заполнены обязательные поля. После прохождения валидации кнопка становится акцентной и доступной для нажатия.

## 3. Структура формы

Экран использует iOS-friendly layout:

- главный верхний блок суммы;
- поле названия магазина или расхода;
- поле категории;
- поле даты;
- вторичное действие `Добавить товары`.

Поле выбора пространства отсутствует. Трата автоматически относится к текущему выбранному пространству, из которого пользователь открыл добавление.

## 4. Валидация

Обязательные поля первой версии:

- сумма;
- название магазина или расхода.

Сумма считается валидной, если строка не пуста и преобразуется в положительное денежное значение. Категория, дата и товарные позиции остаются необязательными.

## 5. Поведение первой версии

- `Добавить товары` остается отдельным действием, но без полноценного редактора позиций в этом шаге.
- Сохранение пока закрывает модалку без записи в backend и служит UI-flow заглушкой.
- Все элементы строятся на системных SwiftUI-компонентах и не имитируют собственный navigation bar вручную.
